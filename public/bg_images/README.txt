BACKGROUND IMAGE

Place the site background image in this folder using this exact filename:

site_bg.jpg

Full path:
public/bg_images/site_bg.jpg

The CSS already references it.

If you prefer PNG, either rename your image to site_bg.jpg after exporting it as JPEG,
or edit /public/assets/styles.css and change:

url("/bg_images/site_bg.jpg")

to your chosen filename.
